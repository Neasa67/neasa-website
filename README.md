# Neasa Hardiman website

A static starting point for a new GitHub Pages website, based on the public content at neasahardiman.com. Open `index.html` in a browser to preview it. Edit `index.html` for content and `style.css` for appearance.

This is a starter, not a full migration: project images, individual project pages, the full archive, and the biography and contact pages have not been copied. The links to those sections currently point to the existing website. Add owned image files and migrate the remaining pages before replacing the existing site.

## Publish with GitHub Pages

1. Create a new repository on GitHub and upload the contents of this folder to its root (including `index.html` and `style.css`).
2. In the repository, open Settings → Pages. Under Build and deployment, choose “Deploy from a branch”, select the default branch and `/ (root)`, then save.
3. GitHub will display the published address in Pages settings after deployment.
4. If you want to use neasahardiman.com, configure the custom domain in GitHub Pages and update the domain's DNS only when the new site is ready. Keep the existing hosting in place until then.
